# PRD — 24시간 비서

## 1. 개요
- **한 줄 소개**: 하루를 설계하고 트렌드를 정리하는 개인 대시보드
- **해결할 문제**: 할 일, 뉴스·인사이트, 내가 만든 프로젝트가 여러 곳에 흩어져 있습니다. 출근 첫 순간에 무엇부터 할지 직접 고르지 않아도, 비서가 동기부여와 함께 하루를 시작하게 해 주는 공간이 필요합니다.
- **이 서비스의 원칙**
  1. **비서가 먼저 말한다**: 앱에 들어가면 사용자가 고르기 전에 AI 동기부여 메시지와 오늘 할 일이 먼저 보입니다.
  2. **입력과 수정은 자유롭게**: 할 일, 목표, 인사이트, 프로젝트 링크는 언제든 바로 추가·수정·삭제할 수 있습니다.
  3. **사무실 같은 한 화면**: PC와 휴대폰 어디서 열어도 출근한 듯한 차분한 업무 공간 느낌을 줍니다.

## 2. 대상 사용자
| 역할 | 누구인가 | 원하는 것 |
|---|---|---|
| 본인(유일한 사용자) | 서비스를 만든 개인. PC와 휴대폰을 모두 사용 | 출근하자마자 동기부여 받기, 오늘·주간·월간 할 일 관리, 뉴스·트렌드 확인과 인사이트 기록, 만든 사이트로 바로 이동 |

- 다른 사람(팀원, 친구)과 공유하거나 함께 쓰는 기능은 없습니다.

## 3. 핵심 기능

### 필수 (MVP)
**1) 로그인 (카카오·구글)**
- 카카오 계정 또는 구글 계정으로 로그인합니다. 별도 회원가입 절차는 없습니다.
- 완료 기준
  - [ ] 카카오 계정으로 로그인하면 대시보드(`/`)로 이동한다
  - [ ] 구글 계정으로 로그인하면 대시보드(`/`)로 이동한다
  - [ ] 로그인하지 않은 상태로 다른 화면에 접근하면 로그인 화면으로 이동한다

**2) AI 동기부여 메시지**
- 하루에 한 번 AI가 새 동기부여 메시지를 만들어 대시보드 맨 위에 보여 줍니다.
- 완료 기준
  - [ ] 그날 처음 대시보드를 열면 새 메시지가 생성되어 맨 위에 표시된다
  - [ ] 같은 날 다시 열면 새로 만들지 않고 저장된 그날의 메시지를 보여 준다
  - [ ] 메시지 생성에 실패하면 "오늘의 메시지를 불러오지 못했어요"와 다시 시도 버튼이 보인다

**3) 플래너 (오늘 할 일 · 이번 주 할 일 · 이번 달 목표)**
- 오늘, 주간, 월간 세 묶음으로 할 일과 목표를 관리합니다.
- 완료 기준
  - [ ] 오늘·주간·월간 각각 항목을 추가, 수정, 삭제, 완료 체크할 수 있다
  - [ ] 대시보드에 오늘 할 일이 동기부여 메시지 바로 아래에 보인다
  - [ ] 새로고침하거나 다른 기기(PC·휴대폰)에서 열어도 같은 내용이 보인다

**4) 뉴스·인사이트 정리**
- EO planet(분야별), Long Black(인기글), 네이버 기반 오늘의 시장 움직임·트렌드를 한 화면에서 보고, 글마다 인사이트를 정리해 저장합니다.
- 완료 기준
  - [ ] 출처별(EO planet / Long Black / 네이버 시장·트렌드)로 글 목록을 볼 수 있고, 클릭하면 원문으로 이동한다
  - [ ] 글을 골라 인사이트를 작성·수정·삭제할 수 있고, 어떤 글에 대한 인사이트인지 함께 저장된다
  - [ ] 저장한 인사이트를 모아 보는 목록이 있다

**5) 마이 프로젝트**
- 내가 만든 사이트들을 카드로 모아 두고 클릭 한 번으로 이동합니다.
- 완료 기준
  - [ ] 프로젝트 이름, 주소(URL), 짧은 설명을 추가·수정·삭제할 수 있다
  - [ ] 카드를 클릭하면 해당 사이트가 새 탭에서 열린다
  - [ ] 잘못된 형식의 주소를 입력하면 저장 전에 안내 문구가 보인다

### 있으면 좋음
- 프로필 화면에서 표시 이름 수정
- 할 일 항목 순서 바꾸기(끌어서 옮기기)
- 인사이트 검색

### 나중
- 캘린더 연동 (사용자가 추후 검토하기로 함)

## 4. 사용자 흐름
**본인 — 아침 출근 흐름**
1. 앱 접속
   - 로그인 안 했을 때 → 로그인 화면(`/login`)에서 카카오 또는 구글로 로그인 → 2번으로
   - 로그인 되어 있을 때 → 바로 2번으로
2. 대시보드 맨 위에서 오늘의 AI 동기부여 메시지 확인
   - 오늘 첫 방문이면 → 새 메시지 생성 후 표시
   - 이미 생성됐으면 → 저장된 메시지 표시
3. 바로 아래 오늘 할 일 확인 → 추가·수정·완료 체크
4. 필요하면 플래너 화면(`/planner`)에서 주간 할 일·월간 목표 확인·수정
5. 뉴스 화면(`/news`)에서 출처별 글 확인 → 원문 읽기 → 인사이트 작성·저장
6. 마이 프로젝트(`/projects`)에서 작업할 사이트 카드 클릭 → 새 탭으로 이동

## 5. 화면 목록
| 화면 | 경로(URL) | 주요 요소 | 누가 보나 |
|---|---|---|---|
| 로그인 | `/login` | 서비스 이름, 카카오 로그인 버튼, 구글 로그인 버튼 | 로그인 안 한 사용자 |
| 대시보드 | `/` | 오늘의 AI 동기부여 메시지, 오늘 할 일(바로 편집), 뉴스·프로젝트 바로가기 | 본인 |
| 플래너 | `/planner` | 오늘 / 이번 주 / 이번 달 탭, 항목 추가·수정·삭제·완료 체크 | 본인 |
| 뉴스·트렌드 | `/news` | 출처별 탭(EO planet, Long Black, 네이버 시장·트렌드), 글 목록, 원문 링크, 인사이트 작성 버튼 | 본인 |
| 인사이트 목록 | `/insights` | 저장한 인사이트 목록(원문 제목·출처·날짜), 수정·삭제 | 본인 |
| 마이 프로젝트 | `/projects` | 프로젝트 카드(이름·설명·주소), 추가·수정·삭제 | 본인 |
| 프로필 | `/profile` | 로그인 계정 정보, 표시 이름, 로그아웃 | 본인 |

- 모든 화면은 반응형(PC와 휴대폰 화면 크기에 맞춰 배치가 바뀌는 방식)으로 만듭니다.

## 6. 데이터 구조
| 테이블 | 주요 컬럼 | 설명 |
|---|---|---|
| profiles | id(글자, 로그인 사용자 ID), display_name(글자), created_at(날짜시간) | 프로필 정보 |
| tasks | id(글자), user_id(글자), period(글자: today/week/month), title(글자), is_done(참/거짓), target_date(날짜), sort_order(정수), created_at(날짜시간), updated_at(날짜시간) | 플래너 할 일·목표. period로 오늘/주간/월간 구분 |
| daily_messages | id(글자), user_id(글자), message_date(날짜), content(글자), created_at(날짜시간) | 하루 한 개의 AI 동기부여 메시지. user_id+message_date 중복 불가 |
| articles | id(글자), source(글자: eo_planet/long_black/naver_market/naver_trend), category(글자), title(글자), url(글자), published_at(날짜시간), fetched_at(날짜시간) | 외부에서 가져온 글 목록. url 중복 불가 |
| insights | id(글자), user_id(글자), article_id(글자, 비어 있을 수 있음), title(글자), content(글자), created_at(날짜시간), updated_at(날짜시간) | 사용자가 정리한 인사이트 |
| projects | id(글자), user_id(글자), name(글자), url(글자), description(글자), sort_order(정수), created_at(날짜시간) | 마이 프로젝트 링크 |

**접근 규칙**
- profiles, tasks, daily_messages, insights, projects에 RLS(행 단위 보안: 자기 데이터만 읽고 쓰게 막는 규칙)를 켭니다. `user_id`(profiles는 `id`)가 로그인한 사용자 ID와 같은 행만 읽기·쓰기 가능합니다.
- articles는 로그인한 사용자만 읽을 수 있고, 쓰기는 서버(글 수집 작업)만 합니다.
- AI API 키 등 비밀 값은 서버에서만 사용하고 브라우저 코드에 넣지 않습니다.

## 7. 추천 기술 스택
| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 화면과 서버 기능(글 수집, AI 호출)을 한 프로젝트에서 처리 |
| 스타일 | Tailwind CSS + shadcn/ui | 디자인 지식 없이도 깔끔한 사무실 느낌 화면을 빠르게 구성 |
| DB·로그인 | Supabase (Postgres, Auth) | 카카오·구글 로그인을 기본 제공하고 무료 플랜으로 시작 가능 |
| AI 메시지 | 미정 (9. 미결 사항 참고) | 어떤 AI 서비스를 쓸지 아직 정하지 않음 |
| 결제 | 사용 안 함 | 본인만 쓰는 무료 서비스 |
| 배포 | Vercel | GitHub 연결만으로 배포, PC·휴대폰 어디서든 접속 |
| 앱 형태 | 반응형 웹 | 모바일 앱이 꼭 필요하다는 요구가 없어 웹 하나로 PC·휴대폰 모두 지원 |

## 8. 만들지 않을 것
- **결제·구독 기능**: 본인만 쓰는 무료 서비스이므로 뺍니다.
- **여러 사용자 공유·팀 기능**: 본인 전용이라 필요 없습니다.
- **캘린더 연동**: 사용자가 추후 검토하기로 했으므로 이번 버전에서 뺍니다.
- **이메일·비밀번호 회원가입**: 카카오·구글 로그인만 사용합니다.
- **알림(푸시·카카오톡 알림)**: 인터뷰에서 요청하지 않았습니다.
- **모바일 앱(앱스토어 배포)**: 반응형 웹으로 충분합니다.

## 9. 미결 사항
- [ ] EO planet, Long Black, 네이버 시장정보·트렌드의 글을 어떤 방식으로 가져올까요? (자동 수집, RSS(새 글 목록을 제공하는 주소), 직접 링크 붙여넣기 중 선택. 각 사이트의 이용약관상 자동 수집이 허용되는지 확인이 필요합니다)
- [ ] Long Black은 유료 구독 콘텐츠인데, 인기글 제목·링크만 보여 주면 될까요, 아니면 본문 내용까지 필요할까요?
- [ ] "네이버 기반의 시장 움직임·트렌드"는 구체적으로 어떤 정보인가요? (예: 네이버 증권 지수, 네이버 데이터랩 검색 트렌드, 네이버 뉴스 경제 섹션)
- [ ] EO planet의 "각 분야"는 어떤 분야들을 보여 줄까요?
- [ ] 인사이트는 직접 작성하나요, 아니면 AI가 글을 요약해 초안을 만들어 주길 원하나요?
- [ ] AI 동기부여 메시지는 무엇을 바탕으로 만들까요? (예: 오늘 할 일·이번 달 목표 반영 여부, 말투·길이)
- [ ] AI 메시지 생성에 어떤 AI 서비스(예: Claude, OpenAI)를 쓸까요? 사용량에 따라 소액 비용이 생길 수 있는데 괜찮나요?
- [ ] 외부 글 목록은 하루에 몇 번 새로 가져올까요? (예: 매일 아침 1회)
- [ ] 완료하지 못한 오늘 할 일은 다음 날로 자동으로 넘길까요, 그대로 둘까요?
