# PRD — MIYA STUDIO

## 1. 개요
- **한 줄 소개**: 하루를 설계하고 트렌드를 정리하는 개인 대시보드
- **해결할 문제**: 할 일, 뉴스·인사이트, 내가 만든 프로젝트가 여러 곳에 흩어져 있습니다. 출근 첫 순간에 무엇부터 할지 직접 고르지 않아도, 비서가 동기부여와 함께 하루를 시작하게 해 주는 공간이 필요합니다.
- **이 서비스의 원칙**
  1. **비서가 먼저 말한다**: 앱에 들어가면 사용자가 고르기 전에 AI 동기부여 메시지와 오늘 할 일이 먼저 보입니다.
  2. **입력과 수정은 자유롭게**: 할 일, 목표, 인사이트, 프로젝트 링크는 언제든 바로 추가·수정·삭제할 수 있습니다.
  3. **사무실 같은 한 화면**: PC와 휴대폰 어디서 열어도 출근한 듯한 차분한 업무 공간 느낌을 줍니다.
  4. **목표만 정하면 된다** (2026-10-08 개편): 목표를 정하면 AI가 할 일을 쪼개서 일정에 넣어 주고, 사용자는 확인하고 실행만 합니다.

## 2. 대상 사용자
| 역할 | 누구인가 | 원하는 것 |
|---|---|---|
| 본인(유일한 사용자) | 서비스를 만든 개인. PC와 휴대폰을 모두 사용 | 출근하자마자 동기부여 받기, 목표를 정하면 AI가 쪼개 준 할 일을 실행하기, 뉴스·트렌드 확인과 인사이트 기록, 만든 사이트로 바로 이동 |

- 다른 사람(팀원, 친구)과 공유하거나 함께 쓰는 기능은 없습니다.

## 3. 핵심 기능

### 필수 (MVP)
**1) 로그인 (카카오·구글)**
- 카카오 계정 또는 구글 계정으로 로그인합니다. 별도 회원가입 절차는 없습니다.
- 완료 기준
  - [ ] 카카오 계정으로 로그인하면 대시보드(`/`)로 이동한다
  - [ ] 구글 계정으로 로그인하면 대시보드(`/`)로 이동한다
  - [ ] 로그인하지 않은 상태로 다른 화면에 접근하면 로그인 화면으로 이동한다

**2) AI 동기부여 메시지**
- 하루에 한 번 AI가 새 동기부여 메시지를 만들어 대시보드 맨 위에 보여 줍니다.
- 완료 기준
  - [ ] 그날 처음 대시보드를 열면 새 메시지가 생성되어 맨 위에 표시된다
  - [ ] 같은 날 다시 열면 새로 만들지 않고 저장된 그날의 메시지를 보여 준다
  - [ ] 메시지 생성에 실패하면 "오늘의 메시지를 불러오지 못했어요"와 다시 시도 버튼이 보인다

**3) 오늘 · 캘린더 · 목표 (2026-10-08 개편, 예전 "루틴" 화면을 대체)**
- 네 가지를 구분합니다.
  - **목표**: 기간이 긴 큰 결과물 (예: 12월까지 전자책 5권)
  - **할 일**: 목표를 쪼갠 실행 단위. 목표와 연결될 수 있고 예상 소요시간이 있음. 직접 추가하거나 AI가 만들며, 화면에서 AI가 만든 것은 반짝이(✦) 표시로 구분
  - **일정**: 시간이 고정된 약속 (예: 금요일 3시 미팅)
  - **루틴**: 반복되는 습관 (예: 매일 아침 뉴스 30분)
- **목표 설정(AI 비서, `/goals`)**: 채팅으로 목표를 대충 말하면 AI가 필요한 것(마감일, 쓸 수 있는 시간, 진행 상태 등)만 묻고, 월 → 주 → 일 단위 계획안을 보여 줍니다. 대화로 고친 뒤 승인하면 할 일이 일정에 자동으로 들어갑니다.
- **오늘(`/`, 메인)**: 맨 위 AI 메시지 → 지금 할 일(가장 크게, 연결된 목표, 완료/나중에) → 오늘 타임라인(할 일·일정·루틴 시간순, 현재 시점 선, 완료 개수) → 빠른 입력(예: "금요일 3시 치과"). 오른쪽에 이번 주 목표별 진척도(%). 할 일이 없으면 AI 비서로 가는 버튼.
- **캘린더(`/calendar`)**: 주간/월간 보기에 할 일·일정·루틴이 모두 보임. 클릭으로 추가·수정·삭제, 끌어서 시간·날짜 이동, 목표별로 이번 주·이번 달 할 일 모아 보기, 루틴 관리.
- **자동 규칙**: AI·자동 배치 할 일은 일할 수 있는 시간(프로필에서 설정) 안의 빈 시간에만 넣고, 일정·루틴과 겹치지 않게 합니다. 하루에 넘치면 다음 날로 넘깁니다. 어제 이전에 못 끝낸 할 일은 다음 빈 시간으로 자동 이월하고, 3번 이상 미루면 쪼갤지(AI)/뺄지 묻습니다. 할 일을 끝내면 연결된 목표의 진척도가 오릅니다.
- 완료 기준
  - [x] AI 비서와 대화해 계획안을 받고, 승인하면 할 일이 빈 시간에 들어간다
  - [x] 빠른 입력 한 줄로 일정/할 일이 저장된다
  - [x] 캘린더에서 항목을 끌어 옮기면 새로고침해도 옮긴 자리에 있다
  - [x] 일정을 할 일 위에 넣으면 할 일이 다음 빈 시간으로 밀려난다
  - [x] 어제 못 끝낸 할 일이 오늘 빈 시간으로 옮겨지고, 3번 미루면 쪼갤지/뺄지 묻는다
  - [x] 새로고침하거나 다른 기기(PC·휴대폰)에서 열어도 같은 내용이 보인다

**4) 뉴스·인사이트 정리** (2026-10-08 수정: 네이버 제외)
- EO planet과 Long Black을 한 화면에 나란히(휴대폰은 위아래) 원래 사이트 모습 그대로 띄워, 각 사이트의 인기글(EO "오늘 많이 본 아티클", Long Black "베스트 노트")을 바로 봅니다. 저장하지 않고 보여 주기만 합니다.
- 읽은 글은 제목·링크만 저장해 두고, 글마다 인사이트를 정리해 저장합니다.
- 네이버는 자동 수집과 다른 사이트 안에 띄우기를 모두 막고 있어 뺐습니다.
- 완료 기준
  - [x] /news에서 EO planet과 Long Black이 한 화면에 같이 보이고, 각 사이트 안의 인기글을 볼 수 있다
  - [ ] 글을 저장해 인사이트를 작성·수정·삭제할 수 있고, 어떤 글에 대한 인사이트인지 함께 저장된다 (서버 키 등록 후 확인)
  - [ ] 저장한 인사이트를 모아 보는 목록이 있다

**5) 마이 프로젝트**
- 내가 만든 사이트들을 카드로 모아 두고 클릭 한 번으로 이동합니다.
- 완료 기준
  - [ ] 프로젝트 이름, 주소(URL), 짧은 설명을 추가·수정·삭제할 수 있다
  - [ ] 카드를 클릭하면 해당 사이트가 새 탭에서 열린다
  - [ ] 잘못된 형식의 주소를 입력하면 저장 전에 안내 문구가 보인다

### 있으면 좋음
- 프로필 화면에서 표시 이름 수정
- 할 일 항목 순서 바꾸기(끌어서 옮기기)
- 인사이트 검색

### 나중
- 외부 캘린더(구글 캘린더) 연동, 주간 리뷰 자동화

## 4. 사용자 흐름
**본인 — 아침 출근 흐름**
1. 앱 접속
   - 로그인 안 했을 때 → 로그인 화면(`/login`)에서 카카오 또는 구글로 로그인 → 2번으로
   - 로그인 되어 있을 때 → 바로 2번으로
2. 대시보드 맨 위에서 오늘의 AI 동기부여 메시지 확인
   - 오늘 첫 방문이면 → 새 메시지 생성 후 표시
   - 이미 생성됐으면 → 저장된 메시지 표시
3. 바로 아래 "지금 할 일" 실행 → 완료 또는 나중에, 타임라인으로 오늘 전체 확인, 빠른 입력으로 추가
4. 새 목표가 생기면 목표 화면(`/goals`)에서 AI 비서와 계획 세우기 → 승인 / 계획 조정은 캘린더(`/calendar`)에서
5. 뉴스 화면(`/news`)에서 출처별 글 확인 → 원문 읽기 → 인사이트 작성·저장
6. 마이 프로젝트(`/projects`)에서 작업할 사이트 카드 클릭 → 새 탭으로 이동

## 5. 화면 목록
| 화면 | 경로(URL) | 주요 요소 | 누가 보나 |
|---|---|---|---|
| 로그인 | `/login` | 서비스 이름, 카카오 로그인 버튼, 구글 로그인 버튼 | 로그인 안 한 사용자 |
| 오늘 | `/` | AI 동기부여 메시지, 지금 할 일, 오늘 타임라인, 빠른 입력, 이번 주 목표 진척도 | 본인 |
| 캘린더 | `/calendar` | 주간/월간 보기, 클릭 추가·수정·삭제, 끌어서 옮기기, 목표별 보기, 루틴 관리 | 본인 |
| 목표 | `/goals`, `/goals/new`, `/goals/[id]` | 목표 목록·진척도, AI 비서 대화, 월→주→일 계획안, 승인 | 본인 |
| 뉴스·트렌드 | `/news` | EO planet·Long Black 사이트를 나란히 띄워 인기글 보기, 저장한 글 목록, 인사이트 작성 버튼 | 본인 |
| 인사이트 목록 | `/insights` | 저장한 인사이트 목록(원문 제목·출처·날짜), 수정·삭제 | 본인 |
| 마이 프로젝트 | `/projects` | 프로젝트 카드(이름·설명·주소), 추가·수정·삭제 | 본인 |
| 프로필 | `/profile` | 로그인 계정 정보, 표시 이름, 일할 수 있는 시간, 로그아웃 | 본인 |

- 모든 화면은 반응형(PC와 휴대폰 화면 크기에 맞춰 배치가 바뀌는 방식)으로 만듭니다.

## 6. 데이터 구조
| 테이블 | 주요 컬럼 | 설명 |
|---|---|---|
| profiles | id(글자, 로그인 사용자 ID), display_name(글자), work_days(요일 목록), work_start·work_end(시각), created_at(날짜시간) | 프로필 정보 + 일할 수 있는 시간 |
| goals | id, user_id, title, description, deadline(날짜), weekly_minutes(주당 분), status(draft/active/done/archived), chat(AI 대화 기록), plan(승인 전 계획안), created_at, updated_at | 목표 |
| tasks | id, user_id, goal_id(비어 있을 수 있음), title, estimated_minutes(예상 분), scheduled_at(배치된 시작 시각, 비면 시간 미정), is_done, done_at, source(manual/ai), carry_count(이월 횟수), sort_order, created_at, updated_at | 할 일 |
| events | id, user_id, title, starts_at, ends_at, created_at, updated_at | 일정(시간 고정) |
| routines | id, user_id, title, weekdays(요일 목록), start_time, duration_minutes, created_at, updated_at | 루틴(반복 습관) |
| routine_checks | routine_id, user_id, check_date | 루틴을 어느 날 했는지 |
| daily_messages | id(글자), user_id(글자), message_date(날짜), content(글자), created_at(날짜시간) | 하루 한 개의 AI 동기부여 메시지. user_id+message_date 중복 불가 |
| articles | id(글자), source(글자: eo_planet/long_black. 예전 값 naver_market/naver_trend는 DB가 허용하지만 화면에서 쓰지 않음), category(글자), title(글자), url(글자), published_at(날짜시간), fetched_at(날짜시간) | 외부에서 가져온 글 목록. url 중복 불가 |
| insights | id(글자), user_id(글자), article_id(글자, 비어 있을 수 있음), title(글자), content(글자), created_at(날짜시간), updated_at(날짜시간) | 사용자가 정리한 인사이트 |
| projects | id(글자), user_id(글자), name(글자), url(글자), description(글자), sort_order(정수), created_at(날짜시간) | 마이 프로젝트 링크 |

**접근 규칙**
- profiles, tasks, goals, events, routines, routine_checks, daily_messages, insights, projects에 RLS(행 단위 보안: 자기 데이터만 읽고 쓰게 막는 규칙)를 켭니다. `user_id`(profiles는 `id`)가 로그인한 사용자 ID와 같은 행만 읽기·쓰기 가능합니다.
- articles는 로그인한 사용자만 읽을 수 있고, 쓰기는 서버(글 수집 작업)만 합니다.
- AI API 키 등 비밀 값은 서버에서만 사용하고 브라우저 코드에 넣지 않습니다.

## 7. 추천 기술 스택
| 영역 | 선택 | 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router) + TypeScript | 화면과 서버 기능(글 수집, AI 호출)을 한 프로젝트에서 처리 |
| 스타일 | Tailwind CSS + shadcn/ui | 디자인 지식 없이도 깔끔한 사무실 느낌 화면을 빠르게 구성 |
| DB·로그인 | Supabase (Postgres, Auth) | 카카오·구글 로그인을 기본 제공하고 무료 플랜으로 시작 가능 |
| AI | Claude API | 동기부여 메시지, 목표 비서, 할 일 쪼개기 (DECISIONS.md 참고) |
| 결제 | 사용 안 함 | 본인만 쓰는 무료 서비스 |
| 배포 | Vercel | GitHub 연결만으로 배포, PC·휴대폰 어디서든 접속 |
| 앱 형태 | 반응형 웹 | 모바일 앱이 꼭 필요하다는 요구가 없어 웹 하나로 PC·휴대폰 모두 지원 |

## 8. 만들지 않을 것
- **결제·구독 기능**: 본인만 쓰는 무료 서비스이므로 뺍니다.
- **여러 사용자 공유·팀 기능**: 본인 전용이라 필요 없습니다.
- **외부 캘린더 연동(구글 캘린더 등)**: 나중에 검토합니다. 앱 안의 캘린더 화면은 있습니다.
- **주간 리뷰 자동화**: 나중에 검토합니다.
- **이메일·비밀번호 회원가입**: 카카오·구글 로그인만 사용합니다.
- **알림(푸시·카카오톡 알림)**: 인터뷰에서 요청하지 않았습니다.
- **모바일 앱(앱스토어 배포)**: 반응형 웹으로 충분합니다.
